# Nigehbaan (نگہبان)

VAN's compliance and risk app: reminds before a date, traces the chain until the
proof is in, tracks deadlines, licences, payments and certificates, escalates
what is stuck, and lets anyone raise a concern in confidence.

An app on the VAN platform (this repo). App key `nigehbaan`, page `/nigehbaan`,
API `/api/nigehbaan/*`, tables `ngb_*`. Sign-in, people and roles are the
platform's.

- Build plan: `docs/NIGEHBAAN-PLAN.md`
- Session log: `OP-HANDOFF-NIGEHBAAN.md` (append-only)
- The demo `nigehbaan-demo.html` and the staff note in `docs/` are kept out of
  git while the repository is public (see `.gitignore`). Ask Tahir for them.

State, 7 Oct 2026: plan only. No server code, tables or routes yet.
